# Стек и домен — book-translate

## Стек

| Слой | Чем |
|---|---|
| окружение | uv (`pyproject.toml` + `uv.lock`), Python ≥ 3.10 |
| конфиг | `data/<книга>/book.yaml`, пример `conf/book.example.yaml` |
| растр и маски | Pillow, numpy, scipy (`ndimage`) |
| OCR | tesseract 5: из PATH, исполняемый файл или распакованный каталог |
| вёрстка и PDF | Chrome / Chromium headless |
| PDF ↔ картинки | poppler (`pdftoppm`, `pdftotext`), Ghostscript для сжатия |
| проверки | ruff, pytest, pre-commit с хуком `no_comments.py` |

## Домен

- **Плашка** — блок с переводом поверх скана. На выкройке прозрачная: буквы
  оригинала под ней стёрты.
- **Ядро фото** — маска фото, сжатая на 3 клетки; плашка на него не ложится.
- **Разворот** — скан двух страниц, режется на `a` и `b`.
- **Колонтитул** — строка с названием раздела или именем вверху страницы; без
  перевода не закрывается.

## Внешние зависимости

Сети пайплайн не требует. Перевод страниц делается вне репозитория (модель,
читающая картинки, или человек).
