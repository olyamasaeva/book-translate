# book-translate — что за проект

## Зачем

Читать книги, у которых нет перевода: сканы без текстового слоя, с фото,
выкройками и сносками. Готово, когда в PDF с переводом на странице ничего не
закрыто и не осталось видимого текста оригинала, кроме имён в колонтитулах.

## Модули

| Модуль | Что делает | Точка входа |
|---|---|---|
| `pages.py` | PDF → картинки страниц, развороты на a/b | `book-translate pages` |
| `layout.py` | блоки текста по форме букв, маски чернил и фото, OCR по блокам | `book-translate layout` |
| `bilingual.py` | двуязычный PDF | `book-translate bilingual` |
| `inplace.py` | перевод прямо на странице, подгонка в Chrome | `book-translate inplace` |
| `check.py` | проверка итоговой вёрстки по DOM | `book-translate check` |
| `compress.py` | сжатие PDF для отправки | `book-translate compress` |
| `settings.py` | конфиг книги `book.yaml` | — |
| `tools.py` | tesseract, Chrome, сборочные файлы, проверки путей | — |
| `page_json.py` | перевод страницы в схеме `source`/`translation` | — |

## Данные

Книги — в `data/<книга>/` (или по `workdir` конфига), не в git: сканы и тексты
защищены авторским правом. Сборочные HTML пишутся в `<workdir>/build/`.

## Потребитель результата

Читатель книги: PDF для чтения и отправки.
