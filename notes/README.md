# notes/

Заметки для того, кто чинит: грабли инструментов и отступления от шаблона.

repo-shape: отступление «Конфиг группами», «Версионирование данных», «Логирование прогонов»

- **Конфиг группами.** Параметры — свойства одной книги, вариантов нет; один
  `book.yaml` с проверкой неизвестных полей (BT-1.2).
- **Версионирование данных.** Книги чужие, в репозиторий не попадают ни в git, ни
  в DVC; кеш раскладки воспроизводится командой `layout`.
- **Логирование прогонов.** Метрики прогона — числа `check` (на фото, пустые,
  пересечения, ужатые, видимые слова, не уместилось); их сравнивают до и после
  правки. Регрессию вёрстки удобно ловить сравнением `build/inplace.html` по
  страницам до и после.

## Грабли

- Запускать через `uv run`: системный Python может не иметь scipy нужной версии.
- Отладка страницы: подменить `inplace.separate`, `inplace.shrink_off_photo`,
  `inplace.find_words` обёртками с печатью и вызвать `inplace.page_html(pid)` —
  видно, кто урезал плашку и откуда взялось слово.
