# Перевод книги «<название>» — инструкция переводчику

Книга: <автор/составитель>, <название>, <издательство, год>. О чём книга — одной фразой.
Перевод — для личного пользования, не для публикации. Язык оригинала — <язык>, перевод на <язык>.
Основной текст: <подробный пересказ по абзацам | полный перевод>. Подписи, надписи на схемах и выкройках,
таблицы, загадки, пословицы, песни, сноски — всегда полностью.

## Что делать с каждой страницей

Страницы — `pages/p-NNN[a|b].jpg` (a — левая, b — правая половина разворота). Открыть картинку (Read) и читать
текст глазами; OCR не брать, если он испорчен. На каждую страницу — файл `translation/p-NNN[a|b].json`:

```json
{"page": "p-007a",
 "printed": "12",
 "kind": "text | photo | pattern | mixed | blank | cover | toc",
 "source": "текст оригинала, абзацы через пустую строку, заголовок — отдельная строка с «# »",
 "translation": "перевод в той же разметке",
 "captions": [{"source": "подпись как в книге", "translation": "перевод подписи"}],
 "notes": "сомнения переводчика; что на иллюстрации, если подписи нет"}
```

Названия полей одинаковы для любой пары языков.
`printed` — номер, напечатанный на странице, иначе null.

- Две колонки читать по колонкам: левая сверху вниз, потом правая.
- Перенос слова через строку или колонку склеить.
- Подпись к фото — только в `captions`, не в `translation`.
- Каждая надпись на схеме или выкройке — отдельная подпись в `captions`, текст `source` ровно как напечатано.
  Если одна надпись стоит в двух местах («Front / Back»), писать через « / » в обоих полях — сборка разведёт.
- Колонтитул («Деревня – Имя») — первым абзацем и в `source`, и в `translation`.
- Цитата, песня, загадка — отдельный абзац, который начинается и кончается кавычкой; подпись к ней
  («Загадка из …») — следующим абзацем или строкой сразу после закрывающей кавычки. Кавычка в середине абзаца —
  это не цитата.
- Сноски — в конце `translation` блоком с заголовком из `notes_headings` конфига (например, `Примечания:`), каждая сноска с новой строки: `34 Текст сноски.`
  Авторов источников писать в форме языка перевода (Смит 1901, 18), если так решено для книги;
  соответствия имён — в `source_names` конфига.
- Пустая страница — `kind: blank`, тексты пустые.

## Как переводить

Точно, без украшательств. Мерки, числа, названия тканей и материалов — без округлений.
Имена людей — в форме языка перевода, оригинал в скобках при первом упоминании на странице.
Топонимы — принятым на языке перевода названием, оригинал в скобках; неизвестные — транслитерацией с оригиналом в скобках.
Учреждения — полным названием на языке перевода, без сокращений.

## Словарь терминов (единообразно во всей книге)

| оригинал | перевод | откуда (страница книги, источник) |
|---|---|---|
|  |  |  |

Новый устойчивый термин — перевести по смыслу, оригинал в скобках, дописать в `notes`.
Каждый термин словаря сверять по самой книге (определения вида «X, то есть Y», «X, also called Y») и по профильному
источнику, прежде чем переводить массово.
