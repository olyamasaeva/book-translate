# Как переводить книгу

## Окружение

```bash
uv sync
uv run pre-commit install
```

Вне Python нужны poppler (`pdftoppm`, `pdftotext`), tesseract 5 с языком
оригинала, Chrome или Chromium и Ghostscript. Tesseract берётся из `PATH`
(`tesseract: system`, по умолчанию), по пути к исполняемому файлу или из
распакованного каталога пакета — тогда библиотеки и `tessdata` ищутся внутри него.
Chrome ищется среди обычных имён и путей Linux, macOS и Windows; другой — полем
`chrome`. Если программы нет или она упала, команда останавливается с её именем и
текстом ошибки.

## 1. Конфиг книги

```bash
mkdir -p data/<книга> && cp conf/book.example.yaml data/<книга>/book.yaml
```

Язык книги задаётся явно: без `ocr_lang`, `source_lower`, `source_upper`,
`target_letters`, `target_lang` и `notes_headings` конфиг не загрузится, чтобы
книга не собралась молча с чужими настройками языка.

| Поле | Что |
|---|---|
| `workdir` | каталог книги: в нём `pages/`, `translation/`, `layout/` |
| `output.bilingual`, `output.inplace` | куда писать PDF |
| `page_width_mm`, `page_height_mm` | размер страницы; без высоты — по медианной пропорции сканов |
| `spreads` | `auto` — разворот, если картинка шире высоты в 1,1 раза; `always`; `never` |
| `ocr_lang` | код языка tesseract (`eng`, `fin`, `rus`…) |
| `target_lang` | язык перевода — атрибут `lang` документов |
| `source_lower`, `source_upper` | алфавит оригинала: по нему узнаются слова оригинала на скане |
| `quote_open`, `quote_close` | кавычки обоих языков |
| `attribution_source`, `attribution_target` | слова-подписи к цитатам («Загадка», «Песня») |
| `notes_headings` | заголовок блока сносок в переводе |
| `source_names` | авторы источников в сносках → форма на языке перевода |
| `service_words`, `credit_words` | служебные слова оригинала (см, фото); подписи авторства фото |
| `retypeset_kinds`, `retypeset_ranges` | страницы, которые набираются заново целиком: оглавление, словарь, таблицы |
| `labels` | подписи в PDF: «с.», «перевод не готов», виды страниц; по умолчанию английские |
| `editorial_patterns` | регулярные выражения, которые вырезаются из перевода (пометки вроде «[пересказ]») |
| `note_boilerplate` | фрагменты, по которым служебные фразы выпадают из примечаний переводчика |
| `title` | титул двуязычного PDF — HTML, конфиг доверенный |
| `tesseract`, `chrome` | какие программы запускать |

Конфиг — доверенный файл, как скрипт: он называет программы, которые будут
запущены, и пути, куда пишутся PDF. Чужой конфиг стоит прочитать перед запуском.

## 2. Страницы

```bash
uv run book-translate pages --book data/<книга>/book.yaml книга.pdf
```

Развороты режутся на `a` (левая) и `b` (правая). Если команда сообщает о
текстовом слое, текст можно брать из PDF; если нет — читать глазами по
картинкам: tesseract по сжатому скану даёт кашу.

## 3. Перевод

Инструкция переводчику — `docs/translation-instruction.md`: скопировать в
каталог книги и заполнить словарь терминов.

- Ключевые термины выверить по самой книге до массового перевода: ошибка в
  словаре размножается на сотни страниц. Искать в книге определения вида
  «X, то есть Y».
- Переводить пачками по ~10 страниц параллельно, каждому исполнителю —
  инструкция и список страниц. После — проверить, что все страницы есть, JSON
  валиден, `printed` идут подряд.
- Перевод бывает заметно длиннее оригинала — поэтому плашки растут в белые поля.

## 4. Двуязычный PDF

```bash
uv run book-translate bilingual --book data/<книга>/book.yaml
```

A4 альбомная, скан слева, перевод справа, подписи с оригиналом курсивом. Кегль
подгоняет скрипт в Chrome. Существующий PDF не перезаписывается — для этого
`--force`.

## 5. Перевод прямо на странице

```bash
nice -n 19 uv run book-translate layout  --book data/<книга>/book.yaml --jobs 2
uv run book-translate inplace --book data/<книга>/book.yaml
uv run book-translate check   --book data/<книга>/book.yaml
```

`layout` долгий (секунды на страницу) и пишет кеш в `layout/`, повторный запуск
пропускает готовое. Кеш не знает, по какому скану и языку посчитан: после замены
сканов или `ocr_lang` удалите `layout/`. `inplace` с `--pages p-023a,p-041b
--out sub.pdf` собирает только эти страницы — так удобно разбирать замечания.
Существующий PDF перезаписывается только с `--force`.

Сборочный HTML лежит в `<workdir>/build/inplace.html`; его же читает `check`.

`check` читает итоговую вёрстку из Chrome и печатает: плашки на фото, пустые,
пересечения, ужатые меньше 75% кегля, не уместившиеся и сколько уверенно
распознанных слов со скана не закрыто плашкой. Последнее считается по OCR самого
скана, поэтому не зависит от языка; для правильного счёта нужен верный `ocr_lang`.
Первые три должны быть нулями. Числа держать между прогонами — регрессия видна
сразу.

## 6. Сжать для отправки

```bash
uv run book-translate compress готовый.pdf
```

Сканы — до 150 dpi, текст остаётся векторным; результат — `<имя>-compressed.pdf`
рядом. Книга на две сотни страниц ужимается примерно втрое.

## Спеки

```bash
uv run pytest
```

Без сети, без Chrome и без книги.
