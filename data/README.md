# data/

Каталоги книг: `data/<книга>/book.yaml` и рядом (или по `workdir`) `pages/`,
`translation/`, `layout/`.

В git отсюда идёт только этот файл. Сканы и тексты книг защищены авторским
правом, переводы делаются для личного пользования — в репозиторий они не
попадают ни в каком виде, DVC тоже не нужен.
