# Changelog — book-translate

Обновляется при смене алгоритма, контракта или метрики проверки.

## [0.4.3] — 2026-10-27

- Читалка показывает справки других словарей и корпусов (BT-10.2): у сомнения список
  `lookups` (`source`, `verdict`, `note`), каждая справка — строка в подсказке; справка с
  вердиктом «да» тоже снимает сомнение (бледный пунктир).

## [0.4.1] — 2026-10-06

- Читалка показывает проверку по словарю (BT-10.2): у сомнения поля `checked`, `dictionary`,
  `fix` — вердикт, толкование и правка идут в подсказку; подтверждённое словарём выделено
  бледным пунктиром. На второй книге (глава 48 страниц, финский и карельский) из 645 сомнений проверены все: 491 подчёркнуто бледным,
  157 мест — ярким (правка или нет в словаре).
- Безопасность читалки (ревью Astra): страницы только с идентификатором `p-007`/`p-012a`,
  CSP по хешу скрипта, как в двуязычном PDF; запись через уникальный временный файл,
  без `--force` готовый файл не заменяется и в гонке; деление сомнения на части без
  квадратичной регулярки, слово длиннее 200 знаков не размечается; подпись страницы
  экранируется; `retypeset_verse_paragraphs` проверяется как целое ≥ 0.

## [0.4.0] — 2026-10-06

- Новый шаг `reader` (BT-10): HTML-читалка без сети — оригинал и перевод рядом,
  при наведении подсвечивается пара. Пары — строки стиха или предложения, если их
  поровну, иначе абзац целиком (на второй книге 611 из 622 абзацев сопоставлены точно, 11 —
  целиком). Слова из `doubts` подчёркнуты, подсказка — догадка переводчика и второе
  мнение из `сомнения-astra.tsv`. Выход — `output.reader`, описание — `title.reader_about`.

## [0.3.1] — 2026-10-06

- Перевод на странице: страница, где стихотворных абзацев не меньше
  `retypeset_verse_paragraphs`, набирается заново целиком (BT-2.3). Песни в две
  колонки по блокам раскладывались кусками: строки куплетов разлетались по странице,
  часть оригинала оставалась видна. Вторая книга (порог 3): видимых слов оригинала
  было 15 на 2 страницах, стало 0; набраны заново 9 страниц из 48. По умолчанию
  правило выключено (`0`).

## [0.3.0] — 2026-10-05

- Безопасность: текст перевода экранируется на всех вставках в HTML, включая скрипт
  подгонки; документы несут CSP, разрешающую только скрипт подгонки по хешу и
  картинки `data:`; Chrome работает с песочницей и новым профилем на каждый запуск;
  сборочные HTML пишутся атомарно в `<workdir>/build/`, а не в `/tmp`; PDF не
  перезаписывается без `--force`; идентификаторы страниц и slug проверяются.
- Ошибки tesseract, Chrome, poppler и Ghostscript останавливают работу с понятным
  сообщением; пустой результат упавшего распознавания не попадает в кеш; `check`
  падает, если проверять нечего.
- Переносимость: настройки передаются процессам раскладки через инициализатор;
  Chrome и tesseract ищутся автоматически; размер страницы — `page_width_mm`,
  `page_height_mm` или по пропорции сканов; режим разворотов `spreads`.
- Язык выходных документов: `target_lang`, подписи `labels`, редакторская вычистка
  `editorial_patterns` и `note_boilerplate` — из конфига, по умолчанию английские
  подписи и без вычистки.
- Слова оригинала без регистра (арабское, китайское письмо) и заглавными больше не
  отбрасываются; на эталоне это сдвинуло кегль основного текста на двух страницах.
- Проверка типов полей конфига и перевода страницы.
- Сжатый PDF по умолчанию — `<имя>-compressed.pdf`.

## [0.2.0] — 2026-10-05

  читаются (`page_json.read`).
- Язык книги обязателен в `book.yaml`, значений по умолчанию нет.
