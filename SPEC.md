# Контракт требований — book-translate

Каждый пункт — одно проверяемое утверждение про наблюдаемое поведение снаружи.
У каждого актуального пункта есть спека в `tests/` с маркером
`@pytest.mark.contract("BT-N")`.

Номера не переиспользуются и не перенумеровываются. Изменившееся требование
помечается `[устарел → BT-N]`, новое заводится новым номером.

```bash
uv run pytest -m contract
```

## BT-1 Конфиг книги

- **BT-1.1** Относительные пути в `book.yaml` считаются от каталога самого файла,
  а не от каталога запуска.
- **BT-1.2** Неизвестное поле конфига — ошибка с его именем, а не молчаливый
  дефолт.
- **BT-1.3** Язык книги (`ocr_lang`, алфавит оригинала, буквы перевода, язык
  документа, заголовок сносок) задаётся явно: без него конфиг не загружается,
  язык по умолчанию не подставляется.
- **BT-1.4** Поле неверного типа или значения (строка вместо списка,
  неположительный размер страницы, неизвестный режим разворотов, неизвестная
  подпись) — ошибка при загрузке с именем поля.

## BT-2 Цитаты и песни

- **BT-2.1** Абзац, который начинается кавычкой и кончается закрывающей (подпись
  допустима строкой после), — одна цитата, даже если в нём несколько строф.
- **BT-2.2** Абзац, который только начинается словом в кавычках, — не цитата.

## BT-3 Сноски

- **BT-3.1** Сноски, записанные одной строкой, разводятся по номерам: у каждой
  свой номер и свой текст; авторы источников подставляются в форме языка
  перевода из `source_names`.

## BT-4 Страницы

- **BT-4.1** Картинка шире своей высоты в 1,1 раза режется на левую `a` и правую
  `b` половины; одиночная страница остаётся целой.
- **BT-4.2** Режим разворотов задаётся явно: `never` не режет широкую картинку,
  `always` режет узкую.

## BT-5 Язык оригинала

- **BT-5.1** Буквы слова оригинала берутся по алфавиту из конфига
  (`source_lower`, `source_upper`), а не по латинице: кириллический оригинал не
  теряется.
- **BT-5.2** Уверенно прочитанное слово без регистра (арабское, китайское письмо)
  или набранное заглавными считается словом оригинала; слово со смешанным
  регистром внутри — мусор распознавания.

## BT-6 Выходные файлы

- **BT-6.1** Сжатие не перезаписывает существующий файл с выходным именем.
- **BT-6.2** Сборка PDF не перезаписывает существующий файл без `--force`; отказ
  происходит до запуска Chrome.

## BT-7 Перевод страницы

- **BT-7.1** Перевод страницы читается в схеме `source`/`translation`; файлы с
  ключами `fi`/`ru` читаются так же, вместе с подписями.
- **BT-7.2** Поле перевода неверного типа — ошибка с именем файла и поля.

## BT-8 Безопасность

- **BT-8.1** Идентификатор страницы — только `p-<цифры>[a|b]`: путь, переход по
  каталогам или разметка отвергаются.
- **BT-8.2** `slug` книги — только латинские буквы, цифры, `_` и `-`.
- **BT-8.3** Документы, которые печатает Chrome, несут CSP: выполняется только
  скрипт подгонки (по хешу), картинки — только `data:`, сеть и файлы закрыты.
  Обработчик события, попавший в текст перевода, не исполнится.

## BT-9 Внешние программы

- **BT-9.1** Если программа распознавания завершилась с ошибкой, результатом
  будет исключение, а не пустой TSV (пустой результат иначе попал бы в кеш).
- **BT-9.2** Отсутствующая программа — ошибка с её именем.

## Без спеки — проверяется прогоном

- Вёрстка на странице («ничего не закрыто») зависит от Chrome и кеша раскладки
  книги. Её проверяет `book-translate check` по итоговому DOM; регрессия ловится
  сравнением чисел `check` и `build/inplace.html` по страницам до и после правки.
- Песочница Chrome и CSP проверены вручную: обработчик `onerror` в документе с CSP
  не выполняется, без CSP — выполняется.

## Открытые вопросы

- Письмо справа налево и вертикальное: порядок разворота и колонок, `dir`
  документа — не поддерживаются.
- Письменности без пробелов между словами: подгонка делит текст по пробелам.
- Кеши раскладки и распознавания не хранят, по какому скану, языку и настройкам
  посчитаны; после замены скана кеш надо удалить руками.
