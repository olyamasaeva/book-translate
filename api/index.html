    API

    Собирается из докстрингов: правится код — правится справка.

    Настройки книги

    Настройки одной книги из book.yaml: пути, язык оригинала и перевода, кавычки, подписи к цитатам, сноски.

    Пример — conf/book.example.yaml. Модули пакета получают настройки через configure(book).

    Конфиг книги — доверенный файл: в нём указываются программы, которые будут запущены (chrome, tesseract), и пути, куда пишутся PDF. Чужой конфиг стоит прочитать перед запуском, как чужой скрипт.

    Book dataclass

    tesseract_cmd(threads=1)

    Tesseract и его окружение.

    system — из PATH; путь к файлу — этот исполняемый файл; путь к каталогу — распакованный пакет (usr/bin/tesseract, библиотеки usr/lib/*, языки usr/share/tesseract-ocr/*/tessdata).

    load(path)

    Прочитать book.yaml; относительные пути считаются от каталога файла.

    Страницы

    PDF книги → картинки страниц pages/p-NNN.jpg; разворот режется на p-NNNa (левая) и p-NNNb (правая).

    has_text_layer(pdf)

    Есть ли в PDF текстовый слой: если нет, текст читается глазами по картинкам, а не из PDF.

    run(pdf, pages_dir, dpi=DPI, spreads='auto')

    Растеризовать PDF и разложить страницы; существующие файлы не перезаписываются.

    split(im, spreads='auto')

    Одиночная страница — как есть, разворот — две половины с суффиксами a и b.

    spreads: auto — разворот, если картинка шире своей высоты в 1,1 раза; always — каждая картинка разворот; never — ни одна.

    Сжатие

    Сжать готовый PDF для отправки (мессенджеры, почта): сканы до 150 dpi, текст остаётся векторным.

    run(src, out=None, dpi=DPI)

    Пережать src ghostscript-ом в out (по умолчанию <имя>-compressed.pdf рядом); исходник не трогается.

    CLI

    CLI: book-translate <шаг> --book книга.yaml. Логика — в модулях пакета, здесь только выбор шага.

    Перевод страницы

    Перевод одной страницы — translation/p-NNN.json.

    Поля: source — текст оригинала, translation — перевод, captions — пары подписей с теми же полями. Файлы со старыми ключами fi/ru при чтении переименовываются, переписывать их не нужно.

    read(path)

    Прочитать перевод страницы в схеме source/translation, в каком бы виде он ни был записан.

    Внешние программы

    Внешние программы пайплайна: tesseract, Chrome — и сборочные файлы книги.

    Каждый вызов проверяет код возврата и падает с понятным сообщением: пустой вывод упавшего tesseract не должен попасть в кеш как «на странице нет слов», а упавший Chrome — выдать «замечаний нет».

    Chrome запускается с включённой песочницей и каждый раз с новым профилем во временном каталоге. HTML книги содержит политику CSP: картинки только data:, сеть и файлы недоступны, выполняется лишь сам скрипт подгонки (по хешу), поэтому разметка или обработчики событий, попавшие в текст перевода, не исполнятся.

    ToolError

    Bases: RuntimeError

    Внешняя программа не найдена или завершилась с ошибкой.

    checked_page_ids(pids)

    Проверить идентификаторы страниц (p-007, p-012a): путь из них не собрать.

    dump_dom(binary, html_path)

    DOM страницы после выполнения скрипта подгонки.

    find_chrome(configured=None)

    Chrome из настроек или первый найденный из обычных имён и путей.

    ocr_tsv(tesseract, env, image, lang, psm)

    Распознать картинку tesseract-ом, вернуть TSV по словам.

    print_pdf(binary, html_path, out, force=False)

    Напечатать HTML в PDF. Существующий out не перезаписывается без force; запись — через временный файл.

    write_build_file(build_dir, name, text)

    Записать сборочный файл в build_dir книги атомарно: сначала во временный, потом переименовать.
